# Design Spec — k-sebe-yoga Landing («Возвращение к себе»)

> **Статус:** approved (2026-08-24, Данил)
> **Назначение:** единый источник правды по дизайну лендинга. Любая правка результата вносится сюда ДО изменения `index.html`. Следующая итерация читает этот файл, а не память и не git-историю.
> **Характер:** изысканный-тихий — воздух, лёгкость, крупная элегантная типографика, сдержанная тёплая палитра. Как премиальные мягкие студии. Не паф-панель.

---

## 1. Типографика

| Роль | Шрифт | Примечание |
|------|-------|------------|
| Заголовки (h1, h2, лид) | **Cormorant Garamond** (Google Fonts) | Лёгкий, премиальный, «студийный». Курсив в эмоциональных местах. |
| Тело, мета, кнопки, подпись | **Inter** (Google Fonts), fallback system-ui | Чистый гротеск, контраст с serif. |

- Подгрузка: `<link>` из Google Fonts (cyrillic subset обязателен — контент русский).
- Межстрочные просторные: `line-height: 1.6–1.8` для тела.
- Иерархия жёсткая: h1 → лид → h2 → тело. Крупные h1 с воздухом вокруг.

## 2. Палитра

| Роль | Значение | Использование |
|------|-----------|---------------|
| Фон | `#FFF8EF` (мрамор-беж) | фон страницы |
| Карточки | `#F7EDE1` | подложка card/manifesto/notes |
| Текст | `#3D2F28` (тёплый шоколад) | основной текст — НЕ чёрный |
| Акцент | `#C98153` (терракота) | ТОЛЬКО заголовок-ноу и CTA-кнопка, не размазывать |
| Белый на тонком | `#FFFFFF` | текст на кнопке поверх терракоты |

- Текст на акценте — белый с хорошим контрастом (не `--peach` а `#C98153`, который глубже).
- Воздух и пустое пространство — главный «премиум», а не цвета.

## 3. Герой (критично)

- **Полноширинная обложка на всю длину (edge-to-edge)** — не колонка. Стандарт для event/приглашения: эмоция и message на первом экране (ресёрч 24.08: примаси-эффект, 57% времени above the fold).
- **Заголовок, подзаголовок и CTA — HTML-оверлеем поверх фото**, по центру. Правка текста = правка HTML, не перегенерация.
- **Картинка ЧИСТАЯ — без текста внутри** (без надписей, логотипов, водяных знаков).
- **Женская фигура целиком — НЕ обрезается сверху/снизу.** Полноширинная лента не должна резать голову/ноги. Обложка генерируется панорамным широким кадром, фигура — по центру, в полный рост, с воздухом сверху/снизу; `object-position` центрирует по фигуре.
- Затемнение-градиент поверх фото для читаемости текста на любом кадре.
- Проверка: фигура целиком на мобиле (320–414) и десктопе (1440+).

### Требуемый образ обложки (исходное условие Данил; restored 24.08)
- **Женщина делает йогу НА ВОСХОДЕ (рассвет), на фоне руин** — как Ruinenberg, Потсдам (старый cover-v2).
- Панорамный широкий кадр, фигура в полный рост по центру, голова/ноги не обрезаны, вокруг воздух; гамма тёплая (беж/крем/персик/шалфей), изысканно-тихо, не клише «йога-фитнес».

## 4. Структура секций (контент Юлии сохраняется дословно)

```
1. Hero (чистое фото + оверлей h1 + CTA)
2. Интро-лид (свободная строка)
3. Что это (абзацы + манифест: чувства/желания/интуиция/сила/индивидуальность/таланты)
4. Почему утром?
5. С собой (коврик, одежда, вода, настрой)
6. Контакт / детали (длительность, бесплатно, локация Ruinenberg) + CTA
7. Финальная фраза + footer
```

- Отступы честные и крупные; секции разделены воздухом, не разделителями.
- Сетка проверяется на **320–414px** (docErr=0) — мобильная адаптивность обязательна.

## 5. Правила для Лютика (карточка/обёртка)

- Картинки для лендинга — **всегда без текста внутри**.
- Любая правка результата → сначала внести в эту спеку, потом в `index.html`.
- Готовое → в репо `k-sebe-yoga/` (не в vault design/), с датой в имени если это картинка.
- Валидация адаптивности на мобиле перед сдачей.

## 6. Критерий «не школьник» (чек-лист)

- [ ] Одна изящная serif-пара (Cormorant Garamond) + чистый sans-тело, а не системная Georgia.
- [ ] Тёплый шоколад вместо чёрного текста.
- [ ] Один сдержанный акцент-цвет, использованный точечно (CTA + акцент заголовка), а не размазанный.
- [ ] Крупные отступы и воздух, честная сетка.
- [ ] Фото чистое, текст — оверлеем в HTML.
- [ ] Идеально на 320–414px (docErr=0).
