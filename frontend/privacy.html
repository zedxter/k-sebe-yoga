1. Какие данные собираются и зачем

1.1. Шрифты

Сайт использует шрифты Cormorant Garamond (с засечками) и Inter (без засечек). Файлы шрифтов размещены на сервере Сайта и загружаются непосредственно с него. При загрузке шрифтов ваш IP-адрес не передаётся третьим лицам.

Правовая основа — законный интерес (Art. 6(1)(f) GDPR): обеспечение единообразного отображения типографики Сайта.

1.2. GitHub Pages (хостинг)

Сайт размещён на платформе GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). При посещении Сайта серверы GitHub автоматически записывают стандартные данные в журналы доступа (access logs): ваш IP-адрес, тип и версия браузера, операционная система, время запроса, URL страницы и HTTP-статус ответа.

GitHub не имеет права использовать эти данные в своих целях — они обрабатываются исключительно для технического обеспечения работы Сайта (доставка контента, диагностика, безопасность). Подробнее: GitHub Privacy Statement.

GitHub, Inc. может передавать данные в соответствии с юридическими обязательствами. Используя Сайт, вы соглашаетесь с обработкой данных в рамках инфраструктуры GitHub.

1.3. Контакт через Telegram

Сайт содержит ссылку на Telegram-аккаунт инструктора. Переписка в Telegram регулируется Политикой конфиденциальности Telegram. Инструктор не использует эти данные в коммерческих целях и не передаёт их третьим лицам без вашего согласия, за исключением случаев, предусмотренных законодательством.

Сайт не использует файлы cookie, трекеры, системы аналитики (Google Analytics, Яндекс.Метрика и т. п.) или любые другие средства сбора данных о поведении пользователей. Мы не создаём профили посещений и не отслеживаем вас между сессиями.

Обработка данных осуществляется на основании:

3. Ваши права по GDPR (Art. 13–14)

В соответствии со статьями 13 и 14 GDPR вы имеете следующие права:

  • Право на доступ (Art. 15): запросить информацию о том, какие ваши данные обрабатываются.
  • Право на исправление (Art. 16): потребовать исправления неточных или неполных данных.
  • Право на удаление (Art. 17): потребовать удаления ваших данных («право быть забытым»).
  • Право на ограничение обработки (Art. 18): потребовать временного ограничения обработки.
  • Право на переносимость данных (Art. 20): получить ваши данные в машиночитаемом формате.
  • Право на возражение (Art. 21): возражать против обработки на основании законного интереса.
  • Право на отзыв согласия: в любой момент отозвать согласие на обработку, если оно было дано.

Для реализации любого из этих прав напишите в Telegram: @Yulia_yoga_innere_balance. Мы ответим в течение 30 дней (GDPR Art. 12).

Вы также имеете право подать жалобу в регулирующий орган по защите данных вашей страны (в Германии — BfDI).

Мы не продаём, не обмениваем и не передаём ваши персональные данные третьим лицам в маркетинговых или коммерческих целях. Техническая передача данных происходит только при хостинге Сайта (GitHub Pages).
